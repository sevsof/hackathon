# hackathon
Хакатон: автоматизация процесс ручной сортировки писем. Проект разработан в рамках хакатона по курсу "Технологии программирования". Выполнили: Севостьянова София, Ткаченко Диана, Васильева Софья, Плетцова Софья, Солодовникова Анастасия
Суть проекта заключалась в том, чтобы создать программу, которая читает входящие письма из корпоративной почты. Программа должна принять 100 файлов с письмами из директории 'inbox', поступивших на вход, обрабатывать их, далее определять, в какую именно категорию будет идти каждое из писем(сортирует письма по заранее указанным категориям ("spam", "HR" и тд)). После распределения писем, формируется директория "newfolders", а такде лог и статистика. Лог - это запись того, что происходило в программе.
Основной функционал содержит:
1. EmailReader (нужен для прочтения писем из папки inbox, обрабатывает пустые или битвые файлы, продолжая работу, а также работает с текстовыми и JSON-файлами)
2. Classifier (отвечает за определение классификации письма (определяет, к какой категории относится каждое письмо по кодовым словам))
3. MoveToFolder (отвечает за создание папок для каждой из классифицированных категорий, помещает письма из inbox в соответствующую newfolders/категория/)
4. MailLogger (логгирует кадое письмо и сохраняет два JSON-файла: process_log.json (детальный лог событий) и stats.json (статистика по категориям).)
5. main.py (запуск программы)
6. run.sh (запуск программы через Bash-скрипт)
7. тесты (для проверки лючевых ошибок)
Категории были выбраны после анализа содержимого писем из набора данных. Мы выделили наиболее часто встречающиеся типы обращений (инциденты, запросы доступов, проблемы с оборудованием и ПО, мониторинг, документы, HR и спам) и сформировали на их основе правила классификации по ключевым словам.
Чтобы программа могла корректно работать, она должна иметь папку inbox/, а также, если пользователь хочет отсортировать письма по папкам, он должен поместить тексстовые документы в формате .txt в вышеуказанную папку. Если папки inbox нет, то Bush-скрипт её создаст, но обязательно положить туда файлы вручную перед запуском.
Чтобы запустить программу другому человеку, нужно проверить наличие таких файлов как src/main.py (хранящийся в папке src) и run.sh, далее нужно запустить Bash-скрипт (./run.sh). Также надо клонировать репозиторий в VS code через терминал:
git clone https://github.com/sevsof/hackathon.git
cd hackathon
Скрипт проверяет, существует ли папка inbox, если да, то программа запускается через Bash-скрипт, при отсутствии вышеуказанного файла выводится ошибка.
В качестве дополнительного задания наша команда добавила HTML-отчет. Добавили генерацию HTML-отчёта с круговой диаграммой (Plotly/Matplotlib), чтобы бизнес-заказчик мог наглядно видеть процентное распределение писем по категориям (спам, инциденты, запросы доступа) вместо скучного JSON.
